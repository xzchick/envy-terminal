# Contributing

Keep the experience in Terminal. Changes should preserve explicit saving, source attribution, and separation of credentials from model inputs.

Run the unit tests and public-package check before submitting a change. Include meaningful tests for persistence, URL restrictions, source tracking, and credential isolation. Use synthetic people and documents in fixtures. Never submit personal logs, account inventories, passwords, model weights, or screenshots containing private information.

Report security issues with minimal synthetic reproduction details. Do not publish live credentials or private documents in an issue. This is a personal local application, not an audited multi-user service.
